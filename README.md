# APK Translator

Android-приложение для перевода текста внутри APK. Импорт APK, выбор языка оригинала
(или автоопределение), перевод на русский, редактирование строк карточками и сборка
нового подписанного APK.

## Статус

MVP в разработке. Текущая версия умеет:

- импортировать APK и определять движок (Android, Godot, Unity, Unreal, Generic);
- извлекать текст из JSON, CSV/TSV и текстовых файлов внутри APK;
- переводить через Google Cloud Translation API v2 (NMT, без LLM);
- защищать плейсхолдеры (`%s`, `{0}`, `{name}`, HTML-теги);
- показывать строки карточками с редактированием, фильтрами и поиском;
- собирать новый APK, подписывать постоянным ключом приложения и делиться файлом;
- показывать баннер при отсутствии интернета.

Ограничения текущей версии:

- `resources.arsc` (обычные Android-строки) пока не изменяется — нужен apktool-пайплайн;
- содержимое Godot PCK, Unreal `.locres/.pak`, Unity AssetBundle/IL2CPP не изменяется;
- строки в коде, картинках и шрифтах без кириллицы не обрабатываются;
- пересобранный APK подписан новым ключом: установка поверх оригинала может потребовать
  удаления исходного приложения.

## Сборка

Сборка выполняется в GitHub Actions (`.github/workflows/build.yml`). После пуша в `main`
или ручного запуска workflow скачайте APK из артефакта `translatorapk-debug`.

Локально нужен JDK 17 и Android SDK:

```bash
gradle :app:assembleDebug
```

## Ключ Google Translate

1. `console.cloud.google.com` → создать проект.
2. Привязать billing account.
3. APIs & Services → Library → **Cloud Translation API** → Enable.
4. Credentials → Create credentials → API key.
5. Ограничить ключ только Cloud Translation API.

Первые 500 000 символов в месяц бесплатны, дальше $20 за 1 млн символов.
Ключ вводится в настройках приложения и хранится локально.

## Архитектура

- `core/ApkAnalyzer` — импорт, определение движка, извлечение строк.
- `core/TextCodec` — разбор и обратная сборка JSON/CSV/текстовых файлов.
- `core/GoogleTranslator` — Google Translation API v2.
- `core/PlaceholderGuard` — защита плейсхолдеров при переводе.
- `core/ApkBuilder`, `core/ApkSignerUtil` — пересборка и подпись APK.
- `vm/AppViewModel` — состояние, перевод, сборка.
- `ui/` — Compose Material 3 интерфейс.

Движки планируется вынести в единый интерфейс адаптеров:
`detect() → extract() → apply() → pack()`. Сейчас определение движка есть,
глубокая поддержка будет добавляться поэтапно.

## Лицензия и правовое использование

Переводите только те приложения, на которые у вас есть права. Распространение
модифицированных APK может нарушать условия использования и авторские права.
